1. 🔑 GET YOUR GEMINI API KEY:
   → Visit: https://aistudio.google.com
   → Create API key
   → Save in backend/.env

2. ⚙️  CONFIGURE SUPABASE:
   → Run supabase_migration.sql in Supabase SQL Editor
   → Enable Anonymous Auth in Authentication settings
   → Update SUPABASE_URL and SUPABASE_ANON_KEY in app.js

3. 🚀 TEST LOCALLY:
   Backend:
   → cd backend
   → pip install -r requirements.txt
   → python backend.py

   Frontend:
   → Open index_new.html in browser
   → Or use: python -m http.server 8080

4. 🌐 DEPLOY:
   Frontend → Vercel/Netlify
   Backend → Render/Fly.io
   Database → Already on Supabase
